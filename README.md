# aminekun90.github.io

Personal site of Mohamed Amine Bouzahar — https://aminekun90.github.io

Vite, React 19 and TypeScript. Content in English, Dutch, German and French lives in `src/content.ts`. The CV is a
PDF generated in the browser from that same content (`src/cv/ResumeDocument.tsx`).

```bash
npm install
npm run dev      # local server
npm run deploy   # build and publish dist/ to the gh-pages branch
```
